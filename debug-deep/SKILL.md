## Escalation
Use only the technique that answers a specific unresolved question:

1. data/state model
2. control/data flow
3. contracts/invariants
4. logic analysis
5. truth tables for boolean/state combinations
6. fault tree for causal decomposition
7. fishbone for multiple independent cause categories
8. instrumentation
9. reduction
10. MDE
11. root cause
12. minimal fix
13. retest/regression

Do not run every technique automatically.
